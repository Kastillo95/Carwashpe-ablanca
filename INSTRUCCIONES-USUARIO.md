# 🚗 Sistema de Lavado Peña Blanca - Instrucciones de Uso

## 📋 PARA INICIAR LA APLICACIÓN

### Opción 1: Inicio Automático (RECOMENDADO)
1. **Doble clic** en el archivo: `SISTEMA-LAVADO-DEFINITIVO.bat`
2. Esperar 3-5 segundos a que aparezca la ventana del navegador
3. ¡Listo! El sistema ya está funcionando

### Opción 2: Inicio Manual
1. **Doble clic** en el archivo: `INICIAR-CARWASH-AUTOMATICO.bat`
2. Manualmente abrir navegador y ir a: `http://localhost:5000`

## ✅ CARACTERÍSTICAS DEL SISTEMA

### 🔄 **DATOS PERMANENTES**
- ✅ Todos los datos se guardan automáticamente
- ✅ No se pierden al cerrar la aplicación
- ✅ Mantiene historial completo (bitácora)
- ✅ Base de datos PostgreSQL integrada

### 🎯 **FUNCIONES PRINCIPALES**
- 📊 **Dashboard**: Resumen diario de actividades
- 📅 **Citas**: Programar y gestionar citas de lavado
- 🛒 **Facturación Rápida**: Cobrar servicios al instante
- 📦 **Inventario**: Control de productos y stock
- 🧾 **Facturación**: Generar facturas completas
- 👥 **CRM**: Gestión de clientes y promociones
- 📈 **Reportes**: Análisis de ventas y rendimiento

### 💾 **PERSISTENCIA DE DATOS**
- **Servicios**: Lavado básico, completo, premium, etc.
- **Clientes**: Información completa y historial
- **Citas**: Todas las citas programadas y completadas
- **Facturas**: Registro completo de todas las ventas
- **Inventario**: Stock actual y movimientos
- **Reportes**: Estadísticas y análisis históricos

## 🚀 PRIMER USO

1. Ejecutar: `SISTEMA-LAVADO-DEFINITIVO.bat`
2. El sistema automáticamente:
   - Instala dependencias (solo primera vez)
   - Configura base de datos
   - Carga datos iniciales
   - Abre el navegador
3. ¡Comenzar a usar inmediatamente!

## 📞 SOPORTE

Si hay algún problema:
1. Verificar que Node.js esté instalado
2. Ejecutar como Administrador si es necesario
3. Para cerrar: Ctrl+C en la ventana negra o cerrarla
