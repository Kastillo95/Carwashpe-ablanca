# 🚗 GUÍA DE INSTALACIÓN - SISTEMA DE LAVADO PEÑA BLANCA

## 📥 CÓMO OBTENER EL SISTEMA EN TU ESCRITORIO

### MÉTODO 1: Descarga Completa (RECOMENDADO)

1. **Descargar todo el proyecto:**
   - Ve a Files (archivos) en Replit
   - Selecciona "Download as zip" o "Descargar como zip"
   - Guarda el archivo ZIP en tu escritorio

2. **Extraer archivos:**
   - Descomprimir el ZIP en tu escritorio
   - Tendrás una carpeta con todo el sistema

3. **Verificar Node.js:**
   - Descargar desde: https://nodejs.org
   - Instalar versión LTS (Long Term Support)

4. **Usar la aplicación:**
   - Doble clic en: `APLICACION-INDEPENDIENTE.bat`
   - ¡Listo! Sistema funcionando offline

### MÉTODO 2: Crear Paquete Automático

1. **En Replit, ejecutar:**
   ```
   Doble clic en: CREAR-PAQUETE-ESCRITORIO.bat
   ```

2. **Se creará carpeta:** `CarwashPenaBlanca-Escritorio`

3. **Copiar esa carpeta a tu escritorio**

4. **Ejecutar:** `APLICACION-INDEPENDIENTE.bat`

## 🔧 SOLUCIÓN DE PROBLEMAS

### Error: "Node.js no encontrado"
- **Solución:** Instalar Node.js desde https://nodejs.org
- Reiniciar computadora después de instalar

### Error: "No se puede abrir aplicación"
- **Solución:** Clic derecho → "Ejecutar como administrador"

### Error: "Puerto ocupado"
- **Solución:** Cerrar otras aplicaciones que usen puerto 5000
