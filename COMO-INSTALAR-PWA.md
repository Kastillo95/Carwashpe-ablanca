# 📱 INSTALAR COMO APP NATIVA (PWA)

## 🚀 TU SISTEMA AHORA ES UNA PWA!

**Progressive Web App = Aplicación Web que funciona como app nativa**

## 📥 CÓMO INSTALAR EN CUALQUIER DISPOSITIVO

### 🖥️ EN PC/LAPTOP (Windows, Mac, Linux):

#### Opción 1: Chrome/Edge/Opera
1. **Abrir:** http://localhost:5000
2. **Buscar icono de instalación** en barra de direcciones (📱)
3. **Clic en "Instalar"** o "Agregar a aplicaciones"
4. **¡Listo!** Tendrás icono en escritorio

#### Opción 2: Botón automático
1. **Abrir la aplicación en navegador**
2. **Aparecerá botón:** "📱 Instalar App" (esquina superior derecha)
3. **Clic en el botón**
4. **Confirmar instalación**

### 📱 EN MÓVILES/TABLETS:

#### Android:
1. **Abrir Chrome:** http://localhost:5000
2. **Menú (⋮) → "Agregar a pantalla de inicio"**
3. **Escribir nombre:** "Peña Blanca"
4. **Agregar**

#### iPhone/iPad:
1. **Abrir Safari:** http://localhost:5000
2. **Botón compartir (📤)**
3. **"Agregar a pantalla de inicio"**
4. **Agregar**
