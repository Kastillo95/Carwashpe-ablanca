# 🖥️ INSTALACIÓN EN MÚLTIPLES PC

## ✅ SÍ PUEDES INSTALAR EN TODAS LAS PC QUE QUIERAS

### 📂 MÉTODO 1: Copia Directa
1. **Descargar una vez desde Replit** (archivo ZIP)
2. **Descomprimir en USB o carpeta compartida** 
3. **Copiar la carpeta completa a cada PC**
4. **En cada PC:** Doble clic en `APLICACION-INDEPENDIENTE.bat`

### 💾 MÉTODO 2: USB Portable
1. **Copiar todo el sistema a USB**
2. **Conectar USB en cualquier PC**
3. **Ejecutar desde USB:** `APLICACION-INDEPENDIENTE.bat`
4. **Funciona sin instalar nada** (solo requiere Node.js)

### 🏢 MÉTODO 3: Red Local
1. **Instalar en PC principal**
2. **Otras PC acceden vía red:** `http://IP-PC-PRINCIPAL:5000`
3. **Todas comparten la misma base de datos**

## 🖥️ REQUISITOS POR PC

### Mínimos:
- ✅ Windows 7/8/10/11
- ✅ Node.js instalado (nodejs.org)
- ✅ 100MB espacio libre
- ✅ No requiere internet después de instalación

### Recomendados:
- 🖥️ Windows 10/11
- 💾 500MB espacio libre
- 🌐 Navegador moderno (Chrome, Edge, Firefox)
