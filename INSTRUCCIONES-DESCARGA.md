## 🚀 PASOS PARA DESCARGAR

### OPCIÓN 1: Ejecutable Directo
1. **Busca el archivo:** `CarwashPenaBlanca.exe`
2. **Descárgalo** a tu PC
3. **Ejecuta** con doble clic
4. **¡Listo!** - El sistema se abre automáticamente

### OPCIÓN 2: Proyecto Completo
1. **Descarga** toda la carpeta del proyecto
2. **Instala Node.js** (si no lo tienes)
3. **Abre terminal** en la carpeta
4. **Ejecuta:** `npm install`
5. **Ejecuta:** `npm run dev`
6. **Abre:** http://localhost:5000

### OPCIÓN 3: Versión Java
1. **Descarga** la carpeta `java-version/`
2. **Instala Java 17+** (si no lo tienes)
3. **Abre terminal** en java-version/
4. **Ejecuta:** `mvn clean package`
5. **Ejecuta:** `java -jar target/carwash-management-1.0.0.jar`
